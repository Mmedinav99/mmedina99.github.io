Job Application Tracker Project

Martin Medina

Project Overview

The Job Application Tracker is a full-stack web development project designed to help job seekers organize their job applications in one location.

The application will allow users to keep track of companies, positions, application statuses, interviews, salary information, job posting links, requirements, and notes.

Project Features

  • Track job applications
  • Record company and position information
  • Track application status
  • Record interview information
  • Store salary information
  • Save job posting links
  • Add notes and requirements
