From Web to Mobile

Martin Medina

Honors Project

From Web to Mobile: Enhancing a Full-Stack Job Application Tracker for Smartphone Users is the Honors extension of the Job Application Tracker project.

The project will investigate how a mobile-first redesign can improve the usability and efficiency of a full-stack job application tracker for smartphone users.

Mobile Development Focus

  • Mobile-first design
  • Responsive web development
  • Mobile-friendly navigation
  • Touch-friendly controls
  • Mobile-friendly forms
  • Responsive layouts
  • Usability testing

Planned Mobile Features

  • Quick Add Application
  • Application Status Timeline
  • Interview and Follow-Up Reminders
  • Priority Applications
  • Improved Mobile Search and Filtering
