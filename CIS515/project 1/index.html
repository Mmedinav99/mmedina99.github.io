Don’t Get Lost Searching for a Job—Job Application Tracker

Martin Medina

Project

Looking for a job can mean keeping track of a lot of companies, positions, job postings, applications, interviews, salary details, links to job postings, requirements, and dates to follow up. When all this information is spread out across job websites, emails, documents, and notes, it can be hard to remember where an application was sent or what step of the hiring process it is in. The Job Application Tracker was made to give job seekers one place to manage all this information.

The goal of this full-stack web development project is to build an application that helps users organize their job search and keep track of their applications from start to finish. Users will be able to write down details about each job opportunity, such as the company, the position, the application status, interviews, salary details, job posting links, requirements, and personal notes. By having all this information in one place, the application can help users have an understanding of their job search instead of depending on many websites or separate documents.

The project is also being expanded through an honors part called From Web to Mobile: Enhancing a Full-Stack Job Application Tracker for Smartphone Users. This part looks at how the current application can be redesigned to offer an experience on smartphones. Since job seekers might look for jobs and apply using their phones, the application needs to be easy to use and navigate on screens while still keeping its main features.

The honors part will focus on first design, responsive development, mobile usability, and features that work well on mobile devices. The project will have first sketches and redesigned screens that work well on phones. The design will focus on navigation, touch-friendly buttons, clear information, and forms that are simple to use on mobile devices. At least one major feature that works only on mobile will also be added. Ideas for these features include a Quick Add Application form, an Application Status Timeline, reminders for interviews and follow-ups, priority applications, or better search and filtering on mobile.

Testing will be done on screen sizes and browsers to find issues with the design that works on mobile. A small group of people who volunteer will test the version by doing real tasks like adding an application, changing the status of an application, finding a priority application, and moving around the mobile home screen. Their comments will help spot problems with how easy it is to use and make changes.

The main goal of this project is to create a full-stack job application tracker while looking into how mobile-first design can improve the experience for people using smartphones. The honors part gives the project a chance to grow beyond its basic features through research, building for mobile, testing, evaluating how easy it is to use, and listening to what users have to say.
