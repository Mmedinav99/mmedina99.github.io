Don't Get Lost Searching for a Job—Job Application Tracker

Martin Medina

Project Overview

Looking for a job can mean keeping track of many companies, positions, job postings, applications, interviews, salary details, requirements, and follow-up dates. When this information is spread across job websites, emails, documents, and notes, it can be difficult to remember where an application was submitted or what stage of the hiring process it has reached.

The Job Application Tracker is a full-stack web development project designed to help job seekers organize this information in one place. The planned application will allow users to record company names, positions, application statuses, interview details, salary information, job posting links, requirements, and personal notes.

The project also includes an honors extension titled "From Web to Mobile: Enhancing a Full-Stack Job Application Tracker for Smartphone Users." This extension explores how mobile-first design and responsive development can make the tracker easier to use on smartphones.

The honors work will focus on mobile-friendly navigation, readable layouts, touch-friendly controls, simplified forms, and useful features for people managing their job searches from their phones. Responsive testing and user feedback will help identify areas that need improvement.
