About Martin Medina

My name is Martin Medina, and I am a Computer Information Systems student interested in technology, programming, web development, and information systems.

This website was created as part of my CIS-515 - Full Stack Web Development coursework. It serves as a central location for my class projects, assignments, and web development work.

My Website

This website uses a consistent cold steampunk and HUD-inspired design. The Orbitron font, metallic styling, and dark interface help create a professional technology-focused appearance across the different pages.

The website is also designed to be responsive so that the content can adjust to different screen sizes. Bootstrap is now being used to improve the site's responsive structure, navigation, and form components while maintaining the visual style of the original website.
